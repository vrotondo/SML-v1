Small Language Model (SML-v1)

A transformer-based language model built entirely from scratch in PyTorch — no Hugging Face shortcuts. Implements modern LLM techniques including Grouped Query Attention, Rotary Position Embeddings, RMSNorm, and SwiGLU activations, mirroring the Llama architecture.

⚡ Grouped Query Attention for memory efficiency
📐 RoPE embeddings for better positional encoding
🔧 Full training pipeline with custom dataloader
🧪 Demo, verification, and chatbot scripts included
PyTorch Python tiktoken Transformers GQA RoPE
Attention Grouped Query Attention (GQA) — multiple query heads share KV pairs
Position Rotary Position Embeddings (RoPE) — relative position via rotation
Norm RMSNorm — faster than LayerNorm, no mean subtraction
Activation SwiGLU — gated linear unit with Swish, used in Llama
Tokenizer tiktoken (GPT-2 BPE) for subword tokenization
Training Custom dataloader with sliding-window context batching
